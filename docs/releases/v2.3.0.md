4DGS Studio 2.3.0 includes the native macOS viewer, the GSV file specification and the GSV 0.1.0 Python package.

- Open a GSV scene, select individual Gaussians or cameras, and inspect their motion against the timeline.
- Adjust path density, opacity and trail length below the viewport. Create a camera animation and save it separately.
- For a calibrated render view with matching RGB observations, inspect the render and reference side by side and compare PSNR and SSIM.

**macOS** — Download the arm64 ZIP for Apple silicon, unzip it and open the app. The minimum system is macOS 13. The binary is ad-hoc signed and has no Apple notarization. The repository includes the source build instructions.

**Python** — Download the wheel, then run `python -m pip install ./gsv-0.1.0-py3-none-any.whl`. Python 3.10 or later and NumPy are required. The tarball contains the Python source distribution. The SDK example in the repository generates a scene you can open immediately.

**Sample scene** — Open `colored-ring.gsv` to inspect 96 synthetic Gaussians across 48 time samples and two animated cameras.

Use `SHA256SUMS` to verify the downloaded distributions. All code and the included file specification are licensed under MIT.
