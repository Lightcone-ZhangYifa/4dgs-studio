# Reporting a vulnerability

Use **Report a vulnerability** under the repository's **Security** tab to send a private report to the maintainers. Include the affected Studio or SDK version, steps to reproduce, and a description of the impact. For a file parsing issue, a minimal synthetic GSV file or a script that constructs it is usually sufficient.

If private reporting is unavailable, open an issue asking the maintainer to establish a private channel. Share the technical details once that channel is available.
